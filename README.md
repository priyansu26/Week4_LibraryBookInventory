# Library Book Inventory System - Week 4

## Code Refactoring and Optimization

This version continues the Week 3 Library Book Inventory System and focuses on
code readability, maintainability, and performance.

## Project Structure

```text
LibraryBookInventory_Week4/
├── pom.xml
├── README.md
└── src/
    ├── main/
    │   └── java/
    │       ├── Book.java
    │       ├── LibraryService.java
    │       └── LibraryApp.java
    └── test/
        └── java/
            └── LibraryServiceTest.java
```

## Requirements

- JDK 17 or later
- Maven 3.8 or later

## Main Refactoring Changes

1. Replaced `ArrayList<Book>` ISBN searching with `LinkedHashMap<String, Book>`.
2. ISBN lookup, duplicate detection and deletion now use the ISBN as a map key.
3. Centralized book validation in `validateBook()`.
4. Centralized ISBN formatting in `normalizeIsbn()`.
5. Added named constants for menu choices and minimum publication year.
6. Split command-line input into small reusable methods.
7. Improved code formatting and comments.
8. Preserved insertion order using `LinkedHashMap`.
9. Retained JUnit 5 coverage for CRUD operations and edge cases.

## Run the Application

From the project folder:

```bash
mvn compile
```

Then run `LibraryApp` from an IDE.

## Run Unit Tests

```bash
mvn test
```

Maven stores detailed test reports under `target/surefire-reports`.

## Note

The `target` directory is generated by Maven and is not included in the submission ZIP.
